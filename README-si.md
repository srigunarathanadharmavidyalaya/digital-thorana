# ඩිජිටල් තොරණ — Digital Thorana

වෙසක් තොරණක් අනුකරණය කරමින්, භ්‍රමණය වන පියුම් රෝදයක් මත ජාතක කතා ප්‍රදර්ශනය කරන පිරිසිදු HTML/CSS/JS වෙබ් අඩවියකි. සෑම පෙත්තක්ම ජාතක කතා පිටුවකට සම්බන්ධ වන අතර, එහි සජීවීකරණ බෞද්ධ රාමුවක්, දිවෙන/දැල්වෙන ආලෝක, සහ කතාවේ වීඩියෝව/ස්ලයිඩ්ෂෝ එකක් ඇතුළත් වේ.

**සජීවී පෙරදසුන:** `index.html` ඕනෑම බ්‍රවුසරයක විවෘත කරන්න — කිසිදු ගොඩනැගීම් පියවරක් අවශ්‍ය නොවේ.

## ව්‍යාපෘති සැලැස්ම

### ගොනු ව්‍යුහය

```
index.html                   ← ප්‍රධාන පියුම් පිටුව
css/main.css                 ← පියුම් රෝද පිරිසැලසුම, අංශු, ප්‍රතිචාරශීලී
js/main.js                   ← අංශු පද්ධතිය + පෙති ක්ලික් හැසිරවීම
assets/
  shared-css/thorana-frame.css  ← කතා පිටුවේ මායිම් රාමුව + ස්ලයිඩ්ෂෝ ශෛලී
  shared-js/lights.js           ← සජීවී ආලෝක + initSlideshow()
  audio/                        ← ශ්‍රව්‍ය ගොනු තබන්න

stories/
  story-01/                    ← වෙස්සන්තර ජාතකය
    index.html                 ← කතා පිටුව
    css/story.css              ← කතා-විශේෂිත තේමාව
    js/story.js                ← යතුරුපුවරු, ස්වයිප්, අලස පූරණය, වීඩියෝ අවසානය
  story-02/                    ← මහෝසධ ජාතකය (සැකිල්ල සූදානම්)
  story-03/                    ← නිමි ජාතකය
  story-04/ ... story-11/      ← තවම සාදා නැත
```

### ප්‍රධාන පිටුව (index.html)

- **පියුම් රෝදය** 35 තත්පරයකට වරක් වාමාවර්තව 360° භ්‍රමණය වේ.
- **පෙති** (දියමන්ති හැඩැති කාඩ්) රෝදය වටා පිහිටා ඇත. සෑම පෙත්තකම කුඩා රූපයක් සහ අංක ලාංඡනයක් ඇත.
- **අංශු කැන්වසය** මධ්‍යයේ සිට රන්/කහ/රතු/සුදු අංශු විමෝචනය කරයි.
- **හොවර්/නවත්වන්න:** ඩෙස්ක්ටොප් එකේ රෝදය හොවර් කිරීමෙන් නතර වේ; පෙති නම් දිස් වේ. ජංගම දුරකථනයේ නම් සැමවිටම පෙනේ.
- **පෙත්තක් ක්ලික් කරන්න** → කතා පිටුවට යයි.

### කතා පිටු ව්‍යුහය

සෑම කතා පිටුවකම (`stories/story-NN/index.html`):

1. **තොරණ මායිම් රාමුව** — රතු/රන් ඉරි සහ කොන සැරසිලි සහිත සම්පූර්ණ තිර රාමුවකි.
2. **සජීවී ආලෝක කැන්වසය** — මායිම වටා බල්බ දිවීම හෝ අහඹු ලෙස දැල්වීම.
3. **ආපසු බොත්තම** — ප්‍රධාන මෙනුවට ආපසු.
4. **කතා මාතෘකාව** සිංහලෙන් සහ ඉංග්‍රීසියෙන්, භ්‍රමණය වන ධර්ම චක්‍රය සමඟ.
5. **වීඩියෝ ප්‍ලේයරය** — කණ්ඩායමේ කතා වීඩියෝව වාදනය කරයි. වීඩියෝව අවසන් වූ විට, නැවත ධාවනය/ප්‍රධාන මෙනුව බොත්තම් දිස් වේ.
6. **කතා පාඨය** — සිංහලෙන් + ඉංග්‍රීසියෙන් සාරාංශය.
7. **ශ්‍රව්‍ය ප්‍ලේයරය** — විකල්ප පසුබිම් ගායනා/සූත්‍ර (කණ්ඩායම සපයයි).

### නව කතාවක් එකතු කරන්නේ කෙසේද

1. `story-01/` ෆෝල්ඩරය `stories/story-NN/` වෙත පිටපත් කරන්න.
2. `index.html` සංස්කරණය කරන්න:
   - `<title>`, `<h1>`, සිංහල/ඉංග්‍රීසි කතා නම වෙනස් කරන්න.
   - `<img src>` ඔබේ කණ්ඩායමේ raw GitHub URL වලින් ප්‍රතිස්ථාපනය කරන්න.
   - සිංහල + ඉංග්‍රීසි කතා පාඨය යාවත්කාලීන කරන්න.
3. `css/story.css` සංස්කරණය කරන්න — පසුබිම, මාතෘකා වර්ණය, උච්චාරණ වර්ණ වෙනස් කරන්න.
4. `js/story.js` — යතුරුපුවරු/ස්වයිප් කේතය නැවත භාවිත කළ හැක; කතා-විශේෂිත තර්කයක් එක් කරන්න.
5. `index.html` හි පෙත්තක් එකතු කරන්න:
   ```html
   <div class="petal-wrap" style="--i:N">
     <a class="petal-card" href="stories/story-NN/index.html">
       <div class="petal-frame">
         <img class="petal-img" src="..." alt="..." onerror="this.src='assets/img/thumb-placeholder.svg'"/>
         <div class="petal-overlay"></div>
         <span class="petal-num">NN</span>
       </div>
       <span class="petal-label">NAME<br/>Sinhala</span>
     </a>
   </div>
   ```
6. අවශ්‍ය නම් `css/main.css` හි `--petals` වැඩි කරන්න.
7. කුඩා රූපය Wikimedia Commons Jataka රූපයකින් හෝ ඔබේ කණ්ඩායමේ raw GitHub URL එකකින් සකසන්න.

### රූප සහ වීඩියෝ කාර්ය ප්‍රවාහය

- **උපකරණ රූප** දැනට Wikimedia Commons URL + `onerror` ෆෝල්බැක් වේ.
- **කණ්ඩායම් රූප:** ඔබේ GitHub ගබඩාවට උඩුගත කරන්න, පසුව මෙසේ යොමු කරන්න:
  `https://raw.githubusercontent.com/YOUR_USERNAME/digital-thorana/main/stories/story-NN/media/scene-XX.jpg`
- **කණ්ඩායම් වීඩියෝව:** කතා පිටුවේ `<video>` මූලද්‍රව්‍යයක් ඇත. වීඩියෝව අවසන් වූ විට, JavaScript නැවත ධාවනය සහ ප්‍රධාන මෙනුව බොත්තම් පෙන්වයි (බලන්න `stories/story-01/js/story.js`).
- **ශ්‍රව්‍ය:** කණ්ඩායම `<audio src>` උපකරණය ප්‍රතිස්ථාපනය කරයි.

### ආලෝක පද්ධතිය

`assets/shared-js/lights.js` ආකාර දෙකක් සපයයි:

1. **දිවීමේ ආකාරය** (පෙරනිමිය) — බල්බ අනුපිළිවෙලින් මායිම වටා දැල්වේ.
2. **දැල්වීමේ ආකාරය** — වඩාත් සාම්ප්‍රදායික තොරණ හැඟීමක් සඳහා බල්බ අහඹු ලෙස දැල්වේ.

`lights.js` හි ඉහළින් ඇති `MODE` නියතය මගින් මාරු කරන්න (`'chase'` හෝ `'flicker'`).

Magic නියතය `BORDER = 18` CSS `--frame-border` සමග ගැලපිය යුතුය.

- පියුම් පිරිසැලසුම CSS `clip-path: polygon()` භාවිතයෙන් දියමන්ති හැඩැති පෙති කාඩ් නිර්මාණය කරයි. සෑම පෙත්තක්ම `rotate()` + `translateY()` භාවිතයෙන් CSS custom properties සමඟ ස්ථානගත කර ඇත.

- තොරණ රාමුව `repeating-linear-gradient` භාවිතයෙන් ඉරි සහිත මායිමක් නිර්මාණය කරයි.
